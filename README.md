# globalstabilization.org

The website for the **Global Risk & Stabilization Summit**, a Climate Emergencies Forum event hosted by ARC at Renaissance Philanthropy, October 12–13, 2026, in Reykjavík, Iceland.

Live at https://renaissancephilanthropy.github.io/globalstabilization-org/ (moving to https://globalstabilization.org).

## About this repository

This repository holds only the built website, which GitHub Pages serves from the `main` branch. It is generated automatically from a private source repository, and every publish replaces its contents with a single new commit.

**Don't edit files here.** Changes made in this repository are overwritten the next time the site is published, and pull requests can't be merged back into the source.

To report a problem with the site or suggest a correction, email cef@renphil.org.
